## لینک‌های دسترسی (ایران)

|------|--------|

| Cloudflare Workers | اگر باز نشد، از لینک بالا استفاده کنید |

### فعال‌سازی GitHub Pages (یک‌بار)

1. برو به مخزن → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save — چند دقیقه بعد لینک بالا فعال می‌شود

## چرا روی ایرانسل / همراه اول قطع می‌شود؟

دو لایه جدا:

1. **خود سایت** — دامنه `*.workers.dev` و بعضی IPهای Cloudflare روی اپراتورهای موبایل ایران فیلتر یا ناپایدار است. DNS عوض کردن معمولاً کافی نیست.
2. **API هوش مصنوعی** — سرورهای Google / OpenAI / DeepSeek از ایران بدون مسیر جایگزین اغلب در دسترس نیستند. حتی اگر صفحه سایت باز شود، چت ممکن است بدون فیلترشکن یا پروکسی جواب ندهد.

### کارهایی که واقعاً کمک می‌کند

- استفاده از **آدرس GitHub Pages** بالا برای باز شدن صفحه
- در صورت امکان یک **دامنه شخصی** بخر و به Cloudflare Pages وصل کن (دامنه شخصی گاهی بهتر از workers.dev است)
- برای چت روی نت ملی: یا فیلترشکن فقط برای API، یا بعداً یک پروکسی سمت سرور (هزینه‌دار)

DNS عمومی پیشنهادی (اگر فقط مشکل resolve داری):
- `8.8.8.8` / `1.1.1.1` — روی خیلی از خطوط موبایل ایران اثر محدود دارد
