## ویژگی‌ها

- تم تاریک و هکری (Matrix background)
- کاربر خودش کلید Gemini API را وارد می‌کند
- کلید فقط در localStorage مرورگر ذخیره می‌شود
- پشتیبانی از چند مدل Gemini
- چت با حافظه محلی
- کاملاً فرانت‌اند (بدون نیاز به سرور بک‌اند)

## استفاده

1. فایل‌ها را روی هر هاست استاتیک (Cloudflare Pages, GitHub Pages, Netlify, ...) آپلود کنید
2. سایت را باز کنید
3. به بخش **تنظیمات** بروید
4. کلید Gemini خود را از [Google AI Studio](https://aistudio.google.com/app/apikey) بگیرید و وارد کنید
5. ذخیره کنید و شروع به چت کنید

## دیپلوی سریع روی Cloudflare Pages

1. این مخزن را Fork کنید یا مستقیم وصل کنید
2. به [pages.cloudflare.com](https://pages.cloudflare.com) بروید
3. مخزن را وصل کنید
4. Build command را خالی بگذارید (استاتیک است)
5. Output directory را خالی یا `/` بگذارید
6. Deploy

## تکنولوژی

- HTML + CSS + Vanilla JS
- Gemini API (کلید کاربر)
- بدون فریم‌ورک
