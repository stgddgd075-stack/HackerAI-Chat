راهنما و قوانین

چطور استفاده کنیم؟

  1. به تنظیمات برو و ارائه‌دهنده را انتخاب کن (Gemini / ChatGPT / DeepSeek).
  2. کلید API خودت را وارد کن و ذخیره بزن.
  3. در چت پیام بفرست، یا از دکمه‌های عکس / آهنگ / کد / صدا / فایل استفاده کن.
  4. کلید را از سایت رسمی هر سرویس بگیر — ما کلید نمی‌فروشیم و ذخیره سمت سرور نداریم.

قوانین

  • مسئولیت استفاده از کلید و هزینه‌های API با خود کاربر است.
  • از سایت برای فعالیت غیرقانونی استفاده نکنید.
  • کلید را در سیستم عمومی یا اسکرین‌شات عمومی قرار ندهید.
  • محتوای تولیدشده توسط AI ممکن است اشتباه باشد؛ بررسی کنید.
  • سازنده حق تغییر یا توقف سرویس رابط را دارد.

امنیت

کلیدها فقط در مرورگر شما ذخیره می‌شوند. ارتباط مستقیم با سرورهای Google / OpenAI / DeepSeek است. برای امنیت بیشتر از دستگاه شخصی استفاده کنید و پس از کار کلید را پاک کنید.
